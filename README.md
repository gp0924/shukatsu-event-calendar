# 就活イベントカレンダー

指定6社・サービスの公開イベントをまとめた閲覧用Webカレンダーです。

## 機能

- 月・週・一覧表示
- 会社・サービス、開催エリア、キーワードによる絞り込み
- 日程の詳細表示と確認元リンク
- 参考日程・他社主催イベントの表示切替
- 表示対象のCSV保存
- モバイル対応、ライト／ダークテーマ

## データについて

毎日9時（Asia/Tokyo）にPerplexity Computerの定期タスクで6サイトの公開日程を確認し、検証できた差分をGitHub版へ反映します。ブラウザ内で自動収集する仕組みではありません。最終巡回確認日は `data.js` の `asof`、最新件数・収録期間はカレンダー画面に表示します。
公式情報と掲載企業のイベントを初期表示し、二次情報・要確認日程は任意表示としています。参考日程は公式確認済みと混同せず保持します。過去日程も履歴として残します。
同日の午前・午後は1日程に集約しています。開催・受付・参加条件は各イベントの確認元をご確認ください。
会員限定・LINE限定の情報は含みません。

## ファイル構成

- `index.html`：ページの構成
- `style.css`：表示スタイル
- `app.js`：カレンダーの操作・絞り込み
- `data.js`：会社・サービスとイベントデータ、確認元URL
- `.nojekyll`：GitHub Pagesで静的ファイルとして配信するための設定

### 更新手順

1. `data.js` の `window.CALENDAR_DATA` にあるイベントを、確認元と照合して追加・修正します。
2. 全6サイトの巡回が成功した場合のみ `asof` を変更します。部分的な取得失敗は記録し、前回の有効なデータを保持します。画面の確認日・件数・期間はデータから算出します。
3. 検証後に公開ブランチへコミットし、GitHub Pagesのビルド成功と公開画面を確認します。公開処理は遅延・失敗する場合があり、変更・失敗時に通知します。
4. 日付表示は日本時間の現在日付を基準にし、終了表示は日付と確認できた最終終了時刻から判定します。当日で時刻不明の場合は終了と断定しません。

GitHub版のみが定期更新対象です。既存の別ホスティング版は再公開しません。ページから消えただけでは中止・削除とは判断しません。定期タスクが停止している場合は手動更新が必要です。

依存パッケージ・ビルド・バックエンドは不要です。ローカルで確認する場合は、このフォルダーで `python -m http.server 3000` を実行してください。
